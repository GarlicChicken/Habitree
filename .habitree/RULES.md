# 규칙

> [rules.json](rules.json)에서 만든 문서입니다. 고칠 때는 `habitree rules`를 씁니다. 사용자가 바로잡은 것은 무엇을 쓰고 무엇을 하지 않는지 구체적으로 `habitree rules add --scope code --aspect structure --rule "…" --why "…" --feedback "…"`로 남깁니다(범위·관점은 아래 목록에서). 같은 뜻 규칙이 있으면 add가 알려 주고, 그때는 `habitree rules hit <id> --feedback "…"`.

- 규칙 0개 · 피드백 0건 · 마지막 피드백 -
- 패키지에서 바로 읽는 꾸러미: `base`, `task`, `work` (보기: `habitree rules brief <범위>`, 반응하거나 고친 규칙만 여기에 남습니다)
